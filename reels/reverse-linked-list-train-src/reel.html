206. Reverse Linked List
Easy • Linked List
1️⃣ next = curr.next; // bachao
2️⃣ curr.next = prev; // link palto
3️⃣ prev = curr; // aage
4️⃣ curr = next; // aage
⚡ 1 loop • O(n) time • O(1) space
